Scoring Agent
Version 1.2.3

    

    

      
Automates uploading and publishing XtremeLabs scoring scripts, driven by a Module Excel and a folder of .ps1 scripts.

      
Developer: Hafiz Muhammad Ahsan

      
Security: your username and password are never stored. You sign in through your own browser and only the session is kept — and it is cleared automatically after 3 hours of the agent not being used, so you re-verify before the next use. Use Sign out to clear it now, or Reset session to stop everything, close the browser and start clean without restarting the app.
